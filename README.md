# PhaseLab

PhaseLab is a python based Phase Plant preset experimentation toolkit.

It supports three workflows:
- Diffusion: mutate one preset.
- Fusion: blend/combine multiple presets into one.
- Catalyze: generate new "random" presets.

## How to Setup:
- Download the PhaseLab folder, place wherever you like, if placed in user preset folder path defaults to that. (Optional: create an output folder)
- Drag the PhaseLab application (no aluncher) to your desktop or applications folder, double click to open app. 
- Start eperimenting!

## Disclaimers:
- Currently only tested in Mac OS, and currently not possible to use on factory presets (experimental/under construction), user presets prefered.
